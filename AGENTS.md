# Agent naming

The user prefers scientist names for collaborating agents. Use scientist names for new task names and conversational aliases, for example `galileo`, `feynman`, and `turing`.

Current conversational aliases: Galileo handles algorithm review; Feynman handles STM32 and native-build review; Turing handles ESP32, Pico, and tooling. Existing internal agent identifiers may retain their earlier task names.
